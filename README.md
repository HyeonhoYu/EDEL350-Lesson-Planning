# Unit Plan Builder

A guided website for preservice teachers to build a transdisciplinary unit plan step by step and download it as a Word (.docx) or PDF file.

## Features

- Step-by-step sections that follow the unit plan template: unit basics, standards, driving question, learning objectives, assessments, 10 learning activities, resources, differentiation, and reflection
- Driving question tutor (Begin with the End in Mind) that walks students from their standards to an end product, a draft driving question, and evidence of learning
- Plan check that flags missing items, leftover template text, near-duplicate objectives, and standards or objectives not taught in any lesson
- Standards and objectives coverage tables
- Autosave in the browser
- Download as Word or PDF

## Privacy

Everything stays in the student's own browser. Nothing is sent to a server.

## Publish with GitHub Pages

1. Create a new public repository on GitHub.
2. Unzip the file and upload everything inside the `unit-plan-builder` folder to the repository, keeping the `images` folder as it is. (On the repository page, choose Add file, then Upload files, and drag in all the files and the `images` folder at once.)
3. Go to Settings, then Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. After a minute or two, the site will be live at `https://<your-username>.github.io/<repository-name>/`.

## Files

- `index.html`: the whole website
- `images/`: Frog baby character art used throughout the site
- `favicon.png`, `apple-touch-icon.png`: browser tab and phone home screen icons

## Libraries

Loaded from public CDNs: docx 8.5.0, jsPDF 2.5.1, jsPDF-AutoTable 3.8.2, and Google Fonts (Source Serif 4, Atkinson Hyperlegible).
